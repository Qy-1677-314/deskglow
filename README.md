# DeskGlow 桌面美化

一个 Windows 桌面整理工具：把桌面上的所有快捷方式收进屏幕底部正中的玻璃 Dock，支持像手机一样把图标拖成「分组文件夹」；桌面上的文档 / 表格 / 文本 / 文件夹会自动聚合到 Dock 最右侧的「文件收纳」图标；同时可以收拾任务栏（清空中间固定图标、让右侧托盘图标全部常显）。

界面上还带着一组可以自由摆放的**桌面小组件**：时钟、日期、电量、文本、图片，位置、大小、字体、配色全部自己定，做完还能打包成预设文件分享给别人。

界面基于 Electron，图标直接从 Windows 系统缓存提取（128px，带透明通道），无需联网。

## 一、快速开始

1. 首次使用请双击 **`安装依赖.bat`**（已装好则可跳过）
2. 双击 **`启动 DeskGlow.vbs`**（推荐，全程无黑框、不闪窗）；想看启动日志就双击 **`启动 DeskGlow.bat`**
3. Dock 会出现在屏幕底部正中，托盘区出现 DeskGlow 图标（双击可打开控制面板）

> 两个脚本都必须是 **CRLF 换行 + GBK(ANSI) 编码**。如果用编辑器（VS Code 等）改过它们，请确认换行符仍是 CRLF，否则 cmd 解析 `if` 语句块会失败，窗口会一闪而过。

> 关闭控制面板不会退出程序，Dock 会一直驻留。退出请用托盘菜单或控制面板「关于 → 退出」。

快捷键：`Ctrl + Alt + D` 显示 / 隐藏 Dock。

## 发布与更新

不联网。安装包负责第一次安装（或连 Electron 运行时一起换）；平时发一个更新包，对方在已经装好的程序里选中它，程序会自己替换文件再打开。配置、图标缓存、任务栏备份都在用户目录里，安装和更新都不碰。

1. 双击 **`打包发布.bat`**（需要已经装好 Electron 运行时）。压缩要几分钟。
2. 完成后在 `release` 里有两个文件：
   - `DeskGlow-Setup-<版本>.exe`：安装包。对方双击后装到 `%LOCALAPPDATA%\Programs\DeskGlow`，桌面和开始菜单各有一个快捷方式，设置里的「应用」可以卸载。卸载只删程序，不删配置。装过一次再运行安装包，就是覆盖升级。
   - `DeskGlow-<版本>.dgupdate`：更新包。只含程序资源，不含 Electron 本体。
3. 对方打开**已安装**的 DeskGlow，托盘菜单或控制面板「关于 → 安装更新包」，选中 `.dgupdate`。确认后程序关掉，把 `resources` 换掉，再自己打开。
4. 更新包的版本来自 `package.json` 的 `version`。比已安装版本旧的包会被拒绝；版本相同会再问一次。换了 Electron 本身时，发新的安装包，不要只用更新包。
5. 在开发目录里点「安装更新包」不会改源码，只会提示去用安装后的程序。

安装包的确认框是英文（系统打包工具不认中文脚本），装完会弹出中文说明。

## 二、功能是怎么实现的

### 1. 操作面板（控制面板）

一个类 Office 的分栏式窗口，左侧导航 + 右侧内容区，共 6 个页面（顺序：概览 → 快捷方式 → 外观设置 → 分组管理 → 文件收纳 → 关于）：

| 页面 | 内容 |
| --- | --- |
| 概览 | 快捷方式 / 分组 / 收纳文件数量；三张状态卡片本身就是开关（点一下切换 Dock 显示、自动隐藏、开机自启）；「跳转到快捷方式」按钮 |
| 快捷方式 | Dock 上所有图标列表，上移 / 下移 / 移入分组 / 移除；桌面新增但未加入 Dock 的快捷方式可一键添加 |
| 外观设置 | 实时预览、图标大小（含一键「塞进一行」）、间距、离底边距离、**玻璃底板开关**、毛玻璃模糊、圆角、浅/深色玻璃、名称提示、**背景颜色与不透明度**、**图标描边 / 阴影**、**准星放大（倍率 + 渐变个数）**、**悬停浅色底开关与配色**；页面最底部是合并进来的**任务栏整理** |
| 分组管理 | 勾选图标 → 创建分组；重命名 / 解散 / 删除分组；把成员移出分组放回 Dock |
| 文件收纳 | 收纳哪些扩展名（文档、表格、演示、文本…）、是否收纳文件夹和其它类型，实时预览 |
| 关于 | 版本、配置目录、重启、退出 |

所有外观改动都是**实时生效**的，不需要重启。托盘图标**左键单击**即可打开面板。

**① 图标大小 / 一键塞进一行**
「图标大小」滑动条现在覆盖 16–96px。拖动时会实时显示当前要占几行；点「塞进一行」按钮会自动算出**当前屏幕下能排成一行**的最大图标尺寸（必要时同步压缩间距），一键把全部图标塞进一行。

**② 背景颜色与透明度**
「背景」卡片里可以选预设底色或点色块用系统取色器自定义（`跟随主题` 表示随浅色/深色玻璃自动变化）；「背景不透明度」0% 近乎全透、100% 实心。底色通过 `--bg-rgb` 变量注入 `rgba(var(--bg-rgb), α)`，所以渐变、边缘渐隐、毛玻璃都跟着走。

**③ 图标描边与阴影**
- 描边：沿图标自身的透明轮廓（不是方形边框）加一圈颜色，由 8 个方向的 `drop-shadow` 叠加实现，粗细 0.5–4px 可调，颜色可自定义
- 阴影：图标下方的柔和投影，可单独调**模糊 / 下移 / 浓度 / 颜色**
- 分组文件夹、文件收纳图标同样生效

### 2. 快捷方式横向平铺 + 分组收纳

- 位置：屏幕水平居中、任务栏上方（跟随工作区，多显示器切换会自动重新定位）
- 排列：放得下就是一行；放不下会自动排成多行且每行数量均衡。**不再支持滚轮左右滑动**，所有图标一眼可见
- **准星放大**：鼠标指向图标时，中间最大、两边按距离递减（可选 1 / 3 / 5 / 7 / 9 个图标参与，最大倍率 1.0–1.8 可调）。窗口会预留向上溢出的空间，放大后不会被裁掉
- **拖入文件**：从桌面/资源管理器把文件或快捷方式拖到 Dock 上直接加入图标
- **拖出移除**：把 Dock 上的图标拖到 Dock 外松手即从 Dock 移除（仍在「快捷方式」页可重新加回）
- **建分组**：把一个图标拖到另一个图标上松手 → 自动生成文件夹（与手机桌面一致），文件夹图标是 2×2 的成员预览
- **放进已有分组**：把图标拖到文件夹图标上
- **调整顺序**：按住 `Shift` 拖动，或到控制面板「快捷方式」里用箭头
- 点击文件夹 → 弹出简约面板（只有图标网格；底部左侧是分组名双击可改名，右侧是图标数量）
- 右键 Dock 图标：打开 / 在资源管理器中显示 / 从 Dock 移除 / 解散分组
- 右键 Dock 空白处：控制面板 / 重新扫描 / 自动隐藏开关 / 退出
- 自动隐藏：开启后鼠标靠近屏幕底部才滑出，移开 0.6 秒后自动收起（此时 Dock 区域不拦截鼠标点击）

### 3. 任务栏整理

在控制面板「外观设置」页最底部的「任务栏整理」：

- **清空固定图标**：移除任务栏中间所有固定的程序图标（不动正在运行的程序），并清掉任务栏缓存，重启资源管理器后生效
- **托盘图标全部常显**：把 `HKCU\Control Panel\NotifyIconSettings` 下每个图标的 `IsPromoted` 设为 1，并清理旧的托盘图标缓存，让右侧状态栏图标不再折叠进 `^`
- 两个操作都有 **一键还原**

> ⚠️ 这两项会修改 Windows 设置，执行时资源管理器会短暂重启（屏幕闪一下）。
> 程序会在 `%APPDATA%\DeskGlow 桌面美化\taskbar-backup\` 里自动备份固定项 `.lnk`、任务栏与托盘相关注册表，随时可还原。

### 4. 文件聚合图标

Dock 最右侧（分隔线之后）固定一个「文件收纳」图标，带数量角标：

- 自动收集桌面上 `.doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf/.txt/.md/.csv…` 以及文件夹
- 点击展开的面板是**纯图标网格**：每个文件只显示图标 + 文件名 + 扩展名，不显示大小和修改日期
- 面板底部：左下角是无框搜索框，右下角是文件数量；没有标题栏、没有分类标签，更简洁
- 单击打开、右键更多（打开、定位、复制路径）
- 收纳规则在「文件收纳」页随时调整（可增删扩展名、是否收纳文件夹）
- 多行排列时它跟随在最后一个图标之后，单行时固定在右端

### 5. 桌面小组件（元素系统）

控制面板「外观设置」页下方的**小组件**分区，和桌面上的那层透明画布是一体的：

- **添加元素**：分区顶部「添加元素」下拉里选 时钟 / 日期 / 电量 / 文本 / 图片，加几次都行；每个元素自带一个递增序号（时钟、时钟 2、时钟 3…），方便区分
- **调节参数**：列表默认收起平铺，只显示序号、类型徽标、名称和一行摘要（比如 `HH:mm:ss · 本地 · 24 小时`）；点右侧小箭头展开该元素的参数面板，按「时间 / 日期 / 电量」「颜色」「文本」「图片」「位置与大小」「文字」「文字阴影」「背景与边框」分组
- **摆到桌面上**：点「可视化编辑」进入编辑状态 —— 画布接管鼠标、控制面板自动隐藏以免挡住，直接拖动元素；选中后八个方向把手缩放，顶栏可做六种对齐并实时显示坐标与尺寸（要填精确数值就去控制面板的「位置与大小」），方向键微调 1px（`Shift` 加速到 10px）。`Esc` 或「完成」退出
- **虚线框贴着文字**：选中框不是按行高画的，而是按每个字形的真实墨迹（canvas 的 `actualBoundingBox*`）量的，所以框线正好压在文字边缘上，46px 的时钟也不会在上下空出十几像素。你设的「内边距」会原样保留在框与文字之间；手动拖出过宽高的元素则按你定的尺寸画框
- **自动对齐**：拖动（缩放也行）时，元素的左 / 中 / 右、上 / 中 / 下会自动贴合其它元素的同名边以及屏幕中线，命中处拉一条洋红参考线；顶栏「自动对齐」是开关，按住 `Alt` 只取消这一次
- **多选**：`Ctrl` + 点击加选 / 减选，在空白处按住左键拖出选框批量选中（按住 `Ctrl` 框选是追加），`Ctrl + A` 全选；多选后拖动是整组平移，对齐按钮变成「互相对齐」—— 左对齐 = 全部对齐到最左那个元素
- **层级**：画布本身是一个覆盖工作区的透明无边框窗口，平时整层 `setIgnoreMouseEvents(…, { forward: true })` 鼠标穿透，只在编辑状态下抢鼠标；层级沿用与 Dock 完全相同的下沉策略，所以「显示桌面 / `Win + D`」依旧能把小组件露出来，任务栏与普通窗口也不会被盖住
- **分享预设**：「导出预设」生成 `.dskset`（JSON，内含元素配置 + base64 的字体与图片）；对方「导入预设」时可选 **替换**（清掉自己的元素）或 **追加**（保留自己的）。导入的字体以文件 hash 去重，不会重复占空间
- **重置**：维护卡片里「恢复默认小组件」需要点两次确认（3 秒内），避免误触清空版式

> 元素位置用**工作区像素坐标**存，屏幕分辨率变了会按新工作区自动收敛回来，不会跑到屏幕外。

## 四、常见问题

**双击 bat 一闪就没了**
两个原因已在 v1.0.1 修掉：① 脚本曾是 LF 换行 + `chcp 65001`，cmd 解析多行 `if` 语句块会直接报错退出；② 启动脚本检测到 `.compat` 时直接 `start electron.exe`，漏了 `--no-sandbox`，Electron 起来后 GPU 崩溃秒退，看起来就是闪一下。现在统一由 `launch.js` 启动，并把 Electron 独立成子进程后立刻返回；启动痕迹写在 `logs\launch.log`。

**启动后一闪就退出 / 黑框里报 GPU 错误**
部分虚拟机或受管控电脑不允许 Chromium 使用渲染沙箱。主进程监听到 GPU 进程异常时会自动写入 `.compat` 标记并以 `--no-sandbox` 重启，之后每次都会走兼容模式。想手动强制：删除 `.compat` 后执行 `node_modules\electron\dist\electron.exe . --no-sandbox`。

**图标是白底方块或没有图标**
首次启动需要为每个图标调用系统 API 提取图片，40 个图标约需 2–5 秒，完成后会缓存到 `icons/` 目录，之后秒开。若某些 UWP 应用图标异常，可在控制面板移除后重新添加。

**Dock 背后那圈白色描边是什么？**
那是玻璃底板的外框（1px 白边 + 顶部内高光 + 投影）。把「背景不透明度」拖到 0 时，底色没了但边框还会留下，看起来就是一个白色空框。现在可以在「外观设置 → 玻璃质感 → 玻璃底板」一键关掉，Dock 只剩悬空的图标。

**任务栏改完没反应**
Windows 有时会缓存任务栏布局，点一下「重启资源管理器」即可。

**想换回普通桌面**
「外观设置 → 任务栏整理」里点「还原固定项」「还原托盘」，再在「概览」关闭 Dock 即可。

**小组件挡住桌面图标了 / 点桌面没反应**
分两种情况。① 「可视化编辑」状态下画布会接管鼠标（顶栏露在外面），按 `Esc` 或点顶栏「完成」退出即可；② 编辑态之外画布是**整层鼠标穿透**的（`WS_EX_TRANSPARENT`，且每次窗口操作后都会重刷一遍），不会拦任何点击 —— 但小组件和 Dock 一样贴在**桌面层**，被普通窗口盖住时既看不到也点不到，把那个窗口移开或最小化就行。判断方法：在元素位置上右键，如果能弹出桌面菜单就不是画布的问题。

**换了显示器或改了分辨率，小组件跑偏了**
位置存的是工作区像素坐标，屏幕变化时会自动收敛回可见范围；想重新排版就进「可视化编辑」摆一下，再「导出预设」留着下次用。

**导入预设后字体不对**
预设里的 TTF/OTF 会随文件一起带过来并自动加载；但如果预设用的是**本机字体**（没内嵌），对方机器上没装这个字体就会回落到默认字体 —— 想跨机器一致，导字体时选「导入 TTF」那份，而不是只选本机字体。

## 五、技术说明

- Electron 33 + 原生 IPC（`contextIsolation: true`，渲染进程 `nodeIntegration: false`）
- Dock 为透明无边框置顶窗口，宽度按内容精确计算，避免重排抖动
- 图标：C# P/Invoke `PrivateExtractIcons`（exe 内嵌图标）→ `SHGetFileInfo + SHGetImageList(JUMBO)`（文件/文件夹系统图标）→ 缩放为 128px PNG 并缓存
- 任务栏：PowerShell + `reg.exe`，全部操作前自动备份，可逆
- 小组件画布：一块覆盖工作区的透明窗口，待机时 `setIgnoreMouseEvents(true)` 整层穿透（**不加 `forward`**：非编辑态不需要鼠标移动事件，纯 `WS_EX_TRANSPARENT` 最可靠，也免掉鼠标钩子受 UIPI 影响）；`setBounds` / 置顶切换 / 每次下沉层级后都会重刷一次穿透状态，防止窗口操作把该属性冲掉；编辑时切 `alwaysOnTop('floating')` 接管鼠标；层级由 `zorder.ps1` 统一下沉到桌面之上、普通窗口之下
- 小组件资源：自定义 `dgfile://` 协议把 `fonts/`、`images/` 里的文件喂给渲染进程（限定目录、拒绝越界路径），字体用 `FontFace` 加载后家族名为 `DG-<文件名>`
- 农历与节日：内置 1900–2100 的农历表 + 24 节气表，公历 / 农历 / 「第几个星期几」三类节日规则；格式串里 `[方括号]` 内的内容原样输出，不会被当成占位符
- 本机字体：纯 Node 解析 TTF/OTF 的 `name` 表（优先 16 号排版家族名，兼容 `ttcf` 集合），全盘枚举约 200ms，结果缓存 10 分钟
- 配置原子写入（临时文件 + rename），损坏自动备份重建
