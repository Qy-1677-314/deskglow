# DeskGlow 桌面美化

DeskGlow 是一款 Windows 桌面整理程序。它将桌面上的快捷方式集中到屏幕底部居中的玻璃 Dock，并支持以拖放方式建立分组文件夹。桌面上的文档、表格、文本和文件夹会自动归入 Dock 最右侧的「文件收纳」。程序还可以整理任务栏：清除中间区域的固定图标，并使通知区域中的托盘图标全部常显。

桌面另有一组可自由摆放的小组件，包括时钟、日期、电量、文本和图片。位置、尺寸、字体和配色均可单独设置。编排完成后，可将全部元素导出为预设文件，供其他计算机导入。

界面基于 Electron。图标从 Windows 系统缓存提取，尺寸为 128 像素，保留透明通道。程序运行无需联网。

| 2 | 五种元素 | 提供时钟、日期、电量、文本和图片，每种均可重复添加。入口为小组件分区顶部的「添加元素」；进入编辑状态后，画布顶栏提供相同入口 |
| 3 | 可视化编辑 | 在小组件分区顶部选择「可视化编辑」。可用鼠标拖动元素，并用八个方向的手柄缩放。顶栏提供左、中、右与上、中、下六种对齐，并显示像素坐标。方向键以 1 像素微调，`Shift` 与方向键以 10 像素微调，`Esc` 退出编辑。选中框按字体的实际字形测量，与文字边缘对齐 |

| 9 | 外观 | 可调节字号、颜色、字重、斜体、下划线、字间距、行间距和文字阴影，以及背景色、圆角和阴影。元素整体可设置透明度和旋转。图片在元素框内按比例裁切并填充 |
| 10 | 字体来源 | 字体有三种来源。预设字体为常见中英文字体的推荐列表。本机字体为已安装字体的自动枚举，通常超过 300 种。导入的 TTF 与 OTF 在导入后出现在列表中，并随预设一并导出 |
| 11 | 预设文件 | 「导出预设」将全部元素写入一个 `.dskset` 文件，字体与图片内嵌其中。单个文件不超过 8 MB，合计不超过 32 MB。接收方使用「导入预设」还原，可选择替换原有元素，或追加到现有元素之后 |
| 12 | 参数列表 | 小组件分区默认以平铺列表显示元素，每行包含类型徽标、名称和一行摘要。行右侧的「启用」关闭后，该元素不在桌面上显示。选择行末箭头后展开该元素的参数。参数按位置与大小、类型、文字、颜色、背景分组，各组有标题，组间有分隔线 |
| 13 | 窗口层级 | 画布与 Dock 使用同一层级：位于桌面之上、普通窗口之下。显示桌面后仍然可见，且不取得焦点。非编辑状态下整层鼠标穿透（`WS_EX_TRANSPARENT`），并在每次窗口操作后重新设置。桌面图标与右键菜单可正常使用 |
| 14 | 应用程序图标 | 图标为圆角方形，紫蓝渐变底上有半透明 Dock 条和三枚悬浮图标，带透明通道。窗口、托盘、桌面快捷方式和安装包使用同一图标。资源位于 `src/main/assets/`。运行时为 256 像素 PNG，安装包图标为 16 至 256 像素共七档 ICO |

## 一、快速开始

1. 首次使用时双击 **`安装依赖.bat`**。依赖已安装时可跳过。
2. 双击 **`启动 DeskGlow.vbs`** 启动程序。此入口不显示控制台窗口。需要查看启动日志时，双击 **`启动 DeskGlow.bat`**。
3. Dock 出现在屏幕底部居中，通知区域出现 DeskGlow 图标。双击该图标可打开控制面板。

> 上述两个脚本必须使用 **CRLF 换行** 和 **GBK（ANSI）编码**。若经编辑器修改，请确认换行符仍为 CRLF。否则 cmd 无法正确解析 `if` 语句块，窗口会立即关闭。

> 关闭控制面板不会退出程序，Dock 继续驻留。退出请使用托盘菜单，或控制面板「关于 → 退出」。

快捷键：`Ctrl + Alt + D` 显示或隐藏 Dock。

## 发布与更新

程序不联网检查更新。安装包用于首次安装，也可一并更换 Electron 运行时。日常更新分发更新包。接收方在已安装的程序中选择该文件后，程序替换自身文件并重新打开。配置、图标缓存和任务栏备份位于用户目录，安装与更新均不修改这些数据。

1. 双击 **`打包发布.bat`**。执行前须已安装 Electron 运行时。压缩需要数分钟。
2. 完成后，`release` 目录中有两个文件：
   - `DeskGlow-Setup-<版本>.exe`：安装包。双击后安装到 `%LOCALAPPDATA%\Programs\DeskGlow`，并在桌面和「开始」菜单创建快捷方式。可在系统「设置 → 应用」中卸载。卸载只删除程序，不删除配置。对已安装的程序再次运行安装包，即为覆盖升级。
   - `DeskGlow-<版本>.dgupdate`：更新包。只包含程序资源，不包含 Electron 运行时。
3. 在已安装的 DeskGlow 中，打开托盘菜单或控制面板「关于 → 安装更新包」，选择 `.dgupdate`。确认后程序关闭，替换 `resources`，然后重新启动。
4. 更新包的版本号取自 `package.json` 的 `version`。版本低于已安装程序的包会被拒绝。版本相同时，程序会再次确认。更换 Electron 运行时本身时，应发布新的安装包。
5. 在开发目录中选择「安装更新包」不会修改源码。程序会提示改用已安装的副本。

安装包的确认框为英文，因为所用打包工具不接受中文脚本。安装完成后会显示中文说明。

## 二、功能说明

### 1. 控制面板

控制面板为分栏窗口，左侧为导航，右侧为内容，共六个页面，顺序为：概览、快捷方式、外观设置、分组管理、文件收纳、关于。

| 页面 | 内容 |
| --- | --- |
| 概览 | 显示快捷方式、分组和收纳文件的数量。三张状态卡片同时作为开关，可切换 Dock 显示、自动隐藏和开机自启。提供「跳转到快捷方式」 |
| 快捷方式 | 列出 Dock 上的全部图标，支持上移、下移、移入分组和移除。桌面上新增且尚未加入 Dock 的快捷方式可从此处添加 |
| 外观设置 | 提供实时预览，以及图标大小（含「塞进一行」）、间距、离底边距离、玻璃底板、底板边框、毛玻璃模糊、圆角、浅色或深色玻璃、名称提示、背景颜色与不透明度、图标描边与阴影、准星放大（倍率与参与个数）、悬停浅色底及其配色。页面底部为任务栏整理 |
| 分组管理 | 勾选图标后可创建分组，并可重命名、解散或删除分组。可将成员移出分组并放回 Dock |
| 文件收纳 | 设置收纳的扩展名，包括文档、表格、演示文稿和文本等，以及是否收纳文件夹和其他类型。更改后实时预览 |
| 关于 | 显示版本和配置目录，并提供重启与退出 |

外观更改立即生效，无需重启程序。单击托盘图标可打开控制面板。

**图标大小与「塞进一行」**

「图标大小」的范围为 16–96 像素。拖动时，界面显示当前排列所需的行数。选择「塞进一行」后，程序按当前屏幕计算能够单行排列的最大图标尺寸，并在需要时同时缩小间距，使全部图标排成一行。

**背景颜色与不透明度**

「背景」中可以选择预设底色，或通过系统取色器自定义。选择「跟随主题」时，底色随浅色或深色玻璃变化。「背景不透明度」为 0% 时接近全透明，为 100% 时为实色。底色经 `--bg-rgb` 写入 `rgba(var(--bg-rgb), α)`，渐变、边缘渐隐和毛玻璃随之变化。

**底板边框**

「边框」打开时，玻璃底板保留 1 像素外框和顶部内高光。背景不透明度为 0 时底色消失，外框和毛玻璃仍然可见。关闭「边框」后，不透明度为 0 时只保留图标。入口为「外观设置 → 底板 → 边框」。关闭「显示底板」后，边框一并隐藏。

**图标描边与阴影**

- 描边沿图标的透明轮廓绘制，由八个方向的 `drop-shadow` 叠加而成。粗细为 0.5–4 像素，颜色可自定义。
- 阴影为图标下方的投影，可分别调节模糊、下移、浓度和颜色。
- 分组文件夹图标和文件收纳图标使用同一设置。

### 2. 快捷方式与分组

- 位置在屏幕水平居中、任务栏上方，并跟随工作区。切换显示器后自动重新定位。
- 宽度足够时排成一行；不足时自动分为多行，各行数量尽量均衡。全部图标同时可见，不提供横向滚动。
- 准星放大：指针指向某一图标时，该图标最大，两侧图标按距离递减。参与放大的图标数量可选 1、3、5、7、9，最大倍率为 1.0–1.8。窗口为向上溢出预留空间，放大后的图标不会被裁切。
- 从桌面或资源管理器将文件或快捷方式拖到 Dock 上，即可加入。
- 将 Dock 上的图标拖到 Dock 外释放，即从 Dock 移除。该项目仍可在「快捷方式」页重新加入。
- 将一个图标拖到另一个图标上并释放，即建立分组。文件夹图标为成员的 2×2 预览。
- 将图标拖到已有文件夹图标上，即加入该分组。
- 调整顺序时，按住 `Shift` 拖动，或在控制面板「快捷方式」中使用箭头。
- 单击文件夹后弹出面板，面板内为图标网格。底部左侧为分组名称，双击可修改；右侧为图标数量。
- 右键单击图标：打开、在资源管理器中显示、从 Dock 移除、解散分组。
- 右键单击空白处：控制面板、重新扫描、自动隐藏、退出。
- 开启自动隐藏后，指针靠近屏幕底部时 Dock 滑出，离开 0.6 秒后收起。收起时，Dock 区域不拦截单击。

### 3. 任务栏整理

此功能位于控制面板「外观设置」页底部的「任务栏整理」。

- **清除固定图标**：移除任务栏中间区域的全部固定程序图标，不结束正在运行的程序，并清除任务栏缓存。重启资源管理器后生效。
- **托盘图标全部常显**：将 `HKCU\Control Panel\NotifyIconSettings` 下每个图标的 `IsPromoted` 设为 1，并清除旧的托盘图标缓存，使通知区域的图标不再进入溢出面板。
- 两项操作均可还原。

> 这两项会修改 Windows 设置。执行时资源管理器会短暂重启，屏幕闪烁一次。
> 程序在 `%APPDATA%\DeskGlow 桌面美化\taskbar-backup\` 中备份固定项快捷方式，以及任务栏和托盘相关注册表，可随时还原。

### 4. 文件收纳

Dock 最右侧、分隔线之后固定一个「文件收纳」图标，并显示数量角标。

- 自动收集桌面上的文档、表格、演示文稿、PDF、文本和 CSV 等文件，以及文件夹。扩展名包括 `.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx`、`.pdf`、`.txt`、`.md`、`.csv`。
- 单击后展开的面板为图标网格。每个文件显示图标、文件名和扩展名。
- 面板底部左侧为搜索框，右侧为文件数量。面板不设标题栏和分类标签。
- 单击可打开文件。右键菜单提供打开、定位和复制路径。
- 收纳规则在「文件收纳」页调整，可增删扩展名，并可设置是否收纳文件夹。
- 多行排列时，该图标跟随在最后一个图标之后；单行排列时固定在右端。

### 5. 软件文件夹位置

控制面板「文件 → 软件文件夹」中，根目录、快捷方式和文件收纳各有「更改位置」。

- 更改根目录时，两个子文件夹一并迁移。也可以只为「快捷方式」或「文件收纳」指定位置，二者可以位于不同磁盘。
- 迁移前会要求确认。迁移对象为现有文件。重名文件自动附加 `(2)`，不覆盖已有文件。
- 迁移完成后，Dock 图标、收纳排序和已隐藏列表中的路径更新为新位置，并重新提取图标。
- 已修改的行标记为「自定义」。选择「恢复默认位置」后，目录回到 `%USERPROFILE%\DeskGlow\`。

### 6. 桌面小组件

控制面板「外观设置」页下方的小组件分区，与桌面上的透明画布使用同一套数据。

- **添加元素**：在分区顶部的「添加元素」中选择时钟、日期、电量、文本或图片，可重复添加。每个元素带有递增序号，例如「时钟」「时钟 2」「时钟 3」。
- **调节参数**：列表默认收起，显示序号、类型徽标、名称和一行摘要，例如 `HH:mm:ss · 本地 · 24 小时`。选择右侧箭头后展开参数。分组为时间、日期、电量、颜色、文本、图片、位置与大小、文字、文字阴影、背景与边框。
- **在桌面上摆放**：选择「可视化编辑」后，画布接收指针输入，控制面板自动隐藏。拖动元素即可移动。选中后可用八个方向的手柄缩放。顶栏提供六种对齐，并显示坐标与尺寸。精确数值在控制面板的「位置与大小」中填写。方向键以 1 像素微调，`Shift` 与方向键以 10 像素微调。按 `Esc` 或选择「完成」即可退出。
- **选中框**：选中框按每个字形的实际边界测量（Canvas 的 `actualBoundingBox*`），与文字边缘对齐。用户设置的内边距保留在框与文字之间。若已手动指定宽高，选中框按该尺寸绘制。
- **自动对齐**：拖动或缩放时，元素的左、中、右与上、中、下边缘自动贴合其他元素的对应边缘和屏幕中线。对齐处显示洋红色参考线。顶栏「自动对齐」为总开关。按住 `Alt` 仅取消本次吸附。
- **多选**：`Ctrl` 加单击可增加或取消选中。在空白处按住左键拖出选框可批量选中；按住 `Ctrl` 时，框选结果追加到当前选择。`Ctrl + A` 为全选。多选后的拖动为整组平移。对齐改为元素之间相互对齐：左对齐表示全部对齐到最左侧的元素。
- **层级**：画布是覆盖工作区的透明无边框窗口。平时以 `setIgnoreMouseEvents` 使指针穿透，仅在编辑状态下接收指针。层级与 Dock 相同，因此执行显示桌面或 `Win + D` 后，小组件仍然可见，且不覆盖任务栏和普通窗口。
- **预设**：「导出预设」生成 `.dskset` 文件。文件为 JSON，包含元素配置，以及以 Base64 保存的字体和图片。导入时可选择替换，即清除现有元素；或选择追加，即保留现有元素。导入的字体按文件哈希去重。
- **重置**：维护卡片中的「恢复默认小组件」须在 3 秒内确认两次，以降低误清空版式的可能。

> 元素位置以工作区像素坐标保存。分辨率变化后，程序将坐标收敛到新的工作区内。

## 三、目录结构

```
桌面美化软件/
├─ 启动 DeskGlow.vbs        推荐入口。静默启动，不显示控制台
├─ 启动 DeskGlow.bat        调试入口。显示启动信息，失败时保持窗口
├─ 安装依赖.bat             安装运行环境
├─ launch.js                启动器。选择正常或兼容模式，拉起进程后退出
├─ src/
│  ├─ main/                 主进程
│  │  ├─ main.js            窗口、IPC 与托盘
│  │  ├─ store.js           配置读写（config.json）
│  │  ├─ dsk.js             小组件字体与图片、.dskset 预设的导入和导出
│  │  ├─ fonts.js           枚举本机字体。解析 TTF 与 OTF 的 name 表，纯 Node.js 实现
│  │  ├─ shortcuts.js       桌面扫描、快捷方式解析、图标提取
│  │  ├─ taskbar.js         任务栏操作
│  │  ├─ icon-gen.js        应用程序图标生成
│  │  └─ ps/                PowerShell 脚本（inspect、icon-extract、taskbar、battery）
│  ├─ preload.js            渲染进程安全桥
│  └─ renderer/             dock、popup、panel、widget 四套界面
│     └─ widget-fmt.js      小组件格式化（时间、农历、节日、电量、元素默认值；主进程与渲染进程共用）
└─ tools/                   开发调试脚本
```

配置文件：`%APPDATA%\DeskGlow 桌面美化\config.json`  
小组件资源：`%APPDATA%\DeskGlow 桌面美化\fonts\`、`images\`  
图标缓存：`%APPDATA%\DeskGlow 桌面美化\icons\`  
任务栏备份：`%APPDATA%\DeskGlow 桌面美化\taskbar-backup\`

## 四、常见问题

**双击批处理脚本后窗口立即关闭**

此前有两个原因，现已修复。其一，脚本曾使用 LF 换行并执行 `chcp 65001`，cmd 在解析多行 `if` 语句块时直接退出。其二，启动脚本在检测到 `.compat` 时直接执行 `start electron.exe`，未附加 `--no-sandbox`，Electron 因 GPU 进程退出而立即关闭。现在统一由 `launch.js` 启动：Electron 作为子进程运行，启动脚本随即返回。启动记录写入 `logs\launch.log`。

**启动后立即退出，或控制台报告 GPU 错误**

部分虚拟机和受管控的计算机不允许 Chromium 使用渲染沙箱。主进程在 GPU 进程异常时写入 `.compat`，并以 `--no-sandbox` 重新启动。此后每次启动均使用兼容模式。若要手动指定，请删除 `.compat` 后执行 `node_modules\electron\dist\electron.exe . --no-sandbox`。

**图标为白底方块，或没有图标**

首次启动时，程序通过系统接口为每个图标提取图像。约 40 个图标需要 2–5 秒。提取结果缓存于 `icons\`，此后启动即可显示。个别 UWP 应用的图标异常时，可在控制面板中移除后重新添加。

**Dock 周围出现白色描边**

该描边是玻璃底板的边框，由 1 像素外框和顶部内高光组成。背景不透明度为 0 且「边框」打开时，底色消失，外框仍然可见。在「外观设置 → 底板 → 边框」中关闭后，这一圈不再显示。若只保留图标，关闭「显示底板」。

**更改任务栏后界面没有更新**

Windows 有时会缓存任务栏布局。请在控制面板中执行「重启资源管理器」。

**恢复系统默认的桌面排列**

在「外观设置 → 任务栏整理」中选择「还原固定项」和「还原托盘」，再在「概览」中关闭 Dock。

**小组件挡住桌面图标，或无法单击桌面**

编辑状态下，画布接收指针输入，顶栏保持可见。按 `Esc` 或选择顶栏「完成」即可退出。编辑状态之外，画布整层指针穿透（`WS_EX_TRANSPARENT`），并在每次窗口操作后重新设置，不拦截单击。小组件与 Dock 同处桌面层。被普通窗口覆盖时，小组件不可见，也无法单击；移开或最小化该窗口后即可操作桌面。可在元素所在位置单击右键：若出现桌面菜单，则该次单击未被画布拦截。

**更换显示器或更改分辨率后，小组件位置偏移**

位置以工作区像素坐标保存。屏幕变化时，程序将坐标收敛到可见范围。若要重新编排，请进入「可视化编辑」调整，再用「导出预设」保存。

**导入预设后字体不一致**

预设中的 TTF 与 OTF 会随文件导入并自动加载。若预设只记录了本机字体名称、未内嵌字体文件，接收方未安装该字体时将使用默认字体。需要在不同计算机上保持一致时，请在导出前导入 TTF 文件。

## 五、技术说明

- Electron 33，使用原生 IPC（`contextIsolation: true`，渲染进程 `nodeIntegration: false`）。
- Dock 为透明无边框窗口。宽度按内容计算，以降低重排时的抖动。
- 图标提取顺序：对可执行文件使用 C# P/Invoke `PrivateExtractIcons`；对文件和文件夹使用 `SHGetFileInfo` 与 `SHGetImageList(JUMBO)`。结果缩放为 128 像素 PNG 并缓存。
- 任务栏操作使用 PowerShell 与 `reg.exe`。操作前自动备份，并可还原。
- 小组件画布覆盖工作区。待机时调用 `setIgnoreMouseEvents(true)`，整层穿透。非编辑状态不使用 `forward`：此时不需要指针移动事件，只保留 `WS_EX_TRANSPARENT`，也可避免鼠标钩子受用户界面权限隔离（UIPI）限制。执行 `setBounds`、切换置顶或下沉层级之后，都会重新设置穿透，以免窗口操作清除该属性。编辑时切换为 `alwaysOnTop('floating')`，以便接收指针。层级由 `zorder.ps1` 保持在桌面之上、普通窗口之下。
- 小组件资源通过自定义协议 `dgfile://` 提供 `fonts\` 与 `images\` 中的文件。协议限定目录，并拒绝越界路径。字体经 `FontFace` 加载，家族名为 `DG-<文件名>`。
- 农历与节日：内置 1900–2100 年农历表和二十四节气表，以及公历、农历和「第几个星期几」三类节日规则。格式串中，方括号内的内容原样输出，不作为占位符解析。
- 本机字体由 Node.js 解析 TTF 与 OTF 的 `name` 表，优先读取名称标识 16（排版家族名），并兼容 `ttcf` 字体集合。全盘枚举约需 200 毫秒，结果缓存 10 分钟。
- 配置先写入临时文件，再通过重命名完成替换。文件损坏时自动备份并重建。

### 测试：桌面小组件面板

| # | 功能 | 说明 |
| --- | --- | --- |
| 1 | 桌面小组件面板 | 一块独立的玻璃面板，显示日期、时间和电量。面板位于桌面层：显示桌面时仍然可见，打开的程序会覆盖它。按住面板可拖动位置，右键可切换横排或竖排，或打开设置。正式版本已改为可自由摆放的元素，见上文「功能一览」 |
| 2 | 分项设置 | 时间与日期使用格式串，例如 `HH:mm:ss`、`YYYY年M月D日 dddd`、`h:mm A`。可选择预设，也可自行填写。各项可独立开关，并可单独设置字号 |
| 3 | 电量显示 | 百分比文字、进度条和电池图标可以组合使用。接通电源后改为闪电图标，低于阈值时变为红色。台式机没有电池时，该行自动隐藏 |

### 测试：显示桌面、收纳按钮与自动隐藏

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | 放大动画过快，画面抖动 | 「外观设置 → 准星放大」增加「响应速度」，范围为 40–520 毫秒，默认 220 毫秒。仅在准星切换到另一个图标时重新计算；指针在同一图标上的微小移动不打断动画 |
| 2 | 单击任务栏「显示桌面」后界面消失 | `setVisibleOnAllWorkspaces` 在 Windows 上将窗口挂到虚拟桌面层，显示桌面后不再绘制。该调用已移除。另设 Dock 守护：窗口被最小化或隐藏时立即恢复，并以 2 秒为间隔进行兜底重绘和置顶复查 |
| 3 | 收纳按钮收进的是快捷方式 | 「文件收纳」页的按钮改为将桌面上的普通文件和文件夹移入 `DeskGlow\文件收纳`。快捷方式仍由「快捷方式 → 整理到软件文件夹」处理 |
| 4 | 自动隐藏后无法再次展开 | 调用 `setIgnoreMouseEvents` 后，窗口收不到 `mousemove`。现由主进程轮询指针热区（Dock 下沿 56 像素）驱动展开和收起。收起时保留一条 11 像素高的把手 |

### 测试：文件合集与图标自愈

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | 文件合集窗口无法关闭 | 右上角增加关闭按钮。按 `Esc` 可关闭。单击窗口外部或指针离开后自动收起。弹窗可以取得焦点，搜索框可以输入 |
| 2 | 重新扫描后图标变为灰色 | 增加路径自愈：文件移动后，按文件名在桌面、桌面的子文件夹和 DeskGlow 快捷方式目录中查找。扫描范围包含桌面子文件夹中的快捷方式 |
| 3 | 需要程序专用的文件夹 | 首次启动时创建 `%USERPROFILE%\DeskGlow\`，其中包含 `快捷方式\` 与 `文件收纳\`。「快捷方式」页提供「整理到软件文件夹」。「文件收纳」页提供软件文件夹卡片，可打开目录、收纳文件或添加文件 |
| 4 | 将桌面文件拖入文件合集 | 将文件拖到文件合集窗口，或拖到 Dock 上的收纳图标，文件即移动到 `DeskGlow\文件收纳`，桌面上的对应项目随即消失 |
| 5 | PNG 在文件合集中不显示 | 默认收纳扩展名补充图片（png、jpg、gif、webp、bmp、svg、ico、heic、tif 等）、压缩包以及音频和视频。已有配置会自动补充一次 |
| 6 | 放大时图标互相重叠 | 放大时，相邻图标按倍率向左右平移。位移累加，间距保持不变，玻璃条同步变宽 |
