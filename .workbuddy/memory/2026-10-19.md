# 2026-10-19

## DeskGlow 桌面美化软件（Electron）从零搭建

用户需求：桌面美化软件，含 ①类 Office 分栏控制面板 ②桌面快捷方式在屏幕底部居中横向平铺，支持手机式分组文件夹 ③任务栏中间固定图标清空、右侧托盘全部常显 ④doc/表格/txt/文件夹合并为 Dock 最右侧一个图标。

### 技术选型与关键决策
- Electron 33 + 透明无边框置顶窗口做 Dock（`alwaysOnTop: 'floating'`、`skipTaskbar`、宽高按内容精确计算，避免「变窄→竖排→更窄」的重排反馈循环）。
- 图标提取下沉到 C# P/Invoke：`PrivateExtractIcons`（exe）→ `SHGetFileInfo + SHGetImageList(JUMBO 256)`（文件夹/文档）→ 缩放 128px PNG 缓存到 userData/icons。**注意：从 PowerShell 直接调用 `IImageList::GetIcon` 会因 COM 编组失败，必须全部在 C# 内完成。**
- PowerShell 5.1 读取 .ps1 必须带 UTF-8 BOM，否则中文注释导致 ParserError。
- 任务栏：`HKCU\Control Panel\NotifyIconSettings\*\IsPromoted=1` 实现托盘常显；删除 Quick Launch 固定项 + 清 `Taskband\Favorites` 实现清空固定图标；操作前备份到 userData/taskbar-backup（.lnk + reg export），支持还原。
- 布局：`layout: auto|scroll|wrap`，auto 下放得下就单行，否则均衡 2–3 行；多行时「文件收纳」随流排在最后一行，单行时固定在右端。

### 环境坑
- 本机 `ELECTRON_RUN_AS_NODE=1` 常驻，直接跑 electron.exe 会以 node 模式启动（app undefined），需 `env -u ELECTRON_RUN_AS_NODE`。
- npm 下载 electron 二进制报 `unable to verify the first certificate`，改用 `https://npmmirror.com/mirrors/electron/33.2.0/electron-v33.2.0-win32-x64.zip` 手动解压到 `node_modules/electron/dist`。
- 本机 Chromium 沙箱不可用，GPU 进程 0xC0000005 崩溃，必须 `--no-sandbox`（已落地 `.compat` 标记 + launch.js 自动降级）。
- 渲染进程不能声明 `const dg`（与 contextBridge 暴露的 window.dg 冲突，会 SyntaxError），统一用 `const api = window.dg`。

### 自检方式
`electron.exe . --no-sandbox --capture` 会逐窗口 `capturePage()` 截图到 shots/ 后退出，用于无 GUI 环境验证界面。

### 双击 bat 闪退修复（v1.0.1）
用户反馈两个 .bat 双击一闪就没。两个真实原因：
1. bat 是 **LF 换行 + UTF-8 无 BOM + `chcp 65001`**，cmd 解析跨行 `if (...)` 语句块要求 CRLF，LF 会直接报错终止。修复：改为 **CRLF + GBK(ANSI)**，去掉 `chcp`，多行 if 块全部改成 `goto :label`。
2. `.compat` 快速分支**漏了 `--no-sandbox`**：`start "" electron.exe .` → GPU 崩溃 2 秒退出，而 `start` 立即返回，于是黑框闪一下、应用根本没起来。
统一链路：bat/vbs → `ELECTRON_RUN_AS_NODE=1 electron.exe launch.js` → launch.js `spawn(detached, stdio:'ignore')` 后立刻 `exit(0)`，日志写 `logs/launch.log`。main.js 增加 `child-process-gone`(GPU/Utility) → 写 `.compat` + `app.relaunch --no-sandbox`（`compatRestarting` + argv 双重防死循环）。
新增 **`启动 DeskGlow.vbs`**：`WScript.Shell.Environment("PROCESS")("ELECTRON_RUN_AS_NODE")="1"` + `Run(...,0,False)`，双击零闪窗，作为推荐入口。
教训：写 Windows 批处理必须用 Python 转码（`glob('*.bat')` → `encode('gbk')` + CRLF）；Write 工具默认 UTF-8/LF 会坏事。

### v1.1.0 外观增强（图标尺寸/背景色/描边阴影）
1. **一键塞进一行**：panel.js 里 `fitOneRow()` 按 `maxW = round(availWidth*0.94) - 48` 反解最大图标尺寸（必要时压缩 gap 到 2）。注意单行时收纳图标在 `.items` 之外（pinned），宽度只能按 **nApps** 算，不能按 total 算（否则多算一个 itemW）。实测本机 availWidth=1707/DPR1.5，39 个图标的一行解是 icon≈23 / gap≈2。
2. **背景颜色**：CSS 改成 `rgba(var(--bg-rgb), calc(var(--alpha)*1.2))`，JS 按 hex 注入 `--bg-rgb`（空则 removeProperty 回落到主题）。alpha 用乘法而不是加法，保证 0% 真的全透明。
3. **描边/阴影**：整串 `filter: var(--icon-filter)`，描边由 8 方向 `drop-shadow(dx dy 0 color)` 叠加实现（沿 alpha 轮廓，不是方框）；同时对 `.folder`/`.archive-tile`/`.fallback` 生效。
4. **多行布局坑**：`.items` 里「收纳」前面有 `.sep`（1px+margin≈5px）再加一个 gap，合计要预留 **20px**，否则最后一行的收纳会被挤到新的一行（表现为 3 行变 4 行、收纳单独悬在中间）。applyLayout 在 wrap 模式下同时写死 `itemsEl.style.width`（不是 max-width），`.bar` 加 `justify-content:center`，行才不会左对齐。
5. `--capture` 自检截图有「帧滞后」：`focus:tab` 后 900ms 截图会截到上一页，需 ≥1600ms；外观页内容长，另存 `panel-appearance-2.png`（先 scrollTop 到底）。

### v1.2.0 简约化 + 放大动效（15 项改动）
- **文件收纳弹窗重做**：删掉头部（图标/标题/副标题）与分类 tabs；文件改成纯图标网格（图标 + 文件名 + 扩展名，无日期/大小）；底部左侧无框搜索、右侧「N 个文件」。
- **弹窗 bug**：`createPopup` 先设 `popupParams` 再 destroy 旧窗口，旧窗 `closed` 回调把 params 清空 → 新弹窗空白。改为先 destroy（removeAllListeners）再赋值，且 `closed` 里判断 `popupWin === win`。
- **Dock 白框**：用户截图里的白色框 = 玻璃底板 `border + inset 高光 + shadow`（其 opacity 已设 0，只剩余边框）。新增 `appearance.glassOn` 开关（data-glass=false 时背景/边框/阴影/backdrop 全关）。
- **悬停白影**：`appearance.hoverBg {on,color,alpha}` → `--hover-bg` + `data-hoverbg`。
- **准星放大**：`appearance.magnify {count,scale}`，pointermove 时按 `k=(half+1-d)/(half+1)` 设 `--s/--ty/z-index`；CSS `transform: translateY(var(--ty)) scale(var(--s))`，origin 50% 100%。
- **放大被裁**：窗口顶部预留 `--grow = iconH*(scale-1)-11+8(+34 labels)`，`.stage` padding-top 用它，`dock:measure` 高度加 grow；`.items` 改 overflow visible。
- **拖入文件**：document dragenter/dragover/drop + preload `webUtils.getPathForFile`（Electron 32+ 无 File.path）→ items:add。
- **拖出移除**：pointerup 时若落点在 bar 外 26px 且无目标 → items:remove。加 pointercancel / window.blur 兜底。
- **去滚动**：删除 wheel 监听、`.items` 不再 overflow auto；布局固定 auto 换行（面板里的「排列方式」整行删掉），CHROME_W 从 28+8+30 改为 28（齿轮按钮已删除）。
- **面板**：去掉 Dock 齿轮「设置」入口；托盘左键单击开面板；概览三张状态卡合并原来的快速开关（`.tile.toggle` + `.tgl`）；hero 只留「跳转到快捷方式」；导航改为 概览/快捷方式/外观设置/分组管理/文件收纳/关于，任务栏整段并入外观页最底部（`go('taskbar')` 重定向）。

### v1.3.0 六项问题修复
- **文件合集关不掉**：popup 原来 `showInactive()` 拿不到焦点，`blur` 永不触发 → 改 `show()+focus()`；新增右上角关闭按钮、Esc、点击卡片外空白关闭，主进程 `startPopupWatcher` 每 200ms 查光标是否离开 popup/dock/panel（420ms 宽限），离开即 `closePopup()`。
- **重扫后全灰**：根因是桌面 lnk 被移进子文件夹后 items.path 失效 → `missing` 类触发 `grayscale(1)`。新增 `healPaths()`：按 basename / 显示名在扫描结果里找回并改写 path（启动时 + rescan 后都跑）；`scanDesktop` 扫描源扩展为 桌面根 + 桌面子文件夹一层的 lnk/url + `DeskGlow\快捷方式`。实测 39 项中 17 项失效全部可自愈。
- **软件文件夹**：新增 `src/main/vault.js`，`%USERPROFILE%\DeskGlow\{快捷方式,文件收纳}`，`vault.ensure()` 在 whenReady 时调用（安装即建）；`importDesktopShortcuts()` 把桌面根 lnk/url 移入；IPC `vault:open` / `vault:importShortcuts` / `archive:addFiles`。UI：文件收纳页「DeskGlow 软件文件夹」卡 + 快捷方式页「整理到软件文件夹」按钮。
- **拖入文件合集**：popup drop → `archive:addFiles`（`vault.moveInto`，跨盘 cp+unlink，重名加 (2)）→ 文件从桌面移到收纳夹；dock 上拖到 archive 图标同样收纳（`.over-archive` 高亮）。panel 拖入也收纳，三处都 `preventDefault` 防 Electron 导航到 file://。
- **PNG 不显示**：`archive.extensions` 默认补 图片/压缩包/音视频；`store.migrate()` 按「磁盘上的 schema」而非 merge 后的值判断（原 bug：DEFAULTS.schema 覆盖导致迁移永不执行），schema 提到 3 强制补一次。
- **放大挤开**：`applyMagnify` 里按 `dx[i]=dx[i-1]+(w*s[i-1]-w)/2+(w*s[i]-w)/2` 向两侧递推，`transform: translate(var(--tx),var(--ty)) scale(var(--s))`；bar 宽度动态 `baseBarW + extra*2`（transition 0.16s），`dock:measure` 宽度预留 `magPad*2`，避免溢出被窗口裁。
- **自检**：`--capture` 加了推挤诊断（打印相邻 `--s/--tx` 与 barW）、tab 断言、`archive:addFiles` 落地校验、popup 关闭校验；结果 moved=1 landed=true、popup closed=true。

### v1.3.1 三项修复
- **放大响应速度**：`appearance.magnify.speed`（40–520ms，默认 220）；dock.css 的 `.item`/`.bar` transition 改读 `--mag-dur`；`applyMagnify` 加 key 缓存，同一图标上指针微动不再重写样式（消除"抽搐"）。面板外观页新增「响应速度」滑条。
- **显示桌面后 UI 消失（根因）**：`dockWin.setVisibleOnAllWorkspaces(true)` 在 Win11 上会把窗口挂进虚拟桌面层，点任务栏最右「显示桌面」后窗口 visible/topmost 都正常但完全不绘制。移除该调用后立即恢复。另加 `reviveDock()`（minimize/hide 立即恢复 + 2s 兜底 + `webContents.invalidate()` 强制重绘）。
- **自动隐藏在 Windows 上失效**：`setIgnoreMouseEvents(..., {forward:true})` 的 forward 仅 macOS 有效，Windows 下窗口收不到 mousemove → 永不复原。改为主进程 `startDockHoverWatch()` 每 110ms 轮询光标（收起时只看下沿 56px 热区，展开后看整个窗口），命中才关穿透并发 `dock:expand`；带 1.1s 抗抖。collapsed 时 bar 只移出到露出 11px 当把手，且把手背景写死颜色（用户 opacity=0 时也能看见）。
- **收纳按钮**：`vault.importDesktopFiles()` 把桌面普通文件/文件夹移进 `DeskGlow\文件收纳`（跳过 .lnk/.url、desktop.ini、~$ 临时文件），IPC `vault:importFiles`；面板按钮文案改「把桌面文件收进来」，hint 用 `vault.desktopFiles`。`scanDesktop` 递归 `文件收纳` 两层，保证被整体移走的文件夹里的 lnk 仍可路径自愈。
- **自检**：`--capture` 增加 `vault:importFiles` 落地校验（临时文件，测完删除）；结果 moved=1 landed=true，popup closed=true。
