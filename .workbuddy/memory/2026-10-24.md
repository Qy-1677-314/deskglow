## 新增：软件文件夹换位置（快捷方式 / 文件收纳）

- 配置：`store.DEFAULTS.vault = { root: '', shortcuts: '', archive: '' }`，空串 = 默认 `%USERPROFILE%\DeskGlow`；`root` 管两个子文件夹，`shortcuts` / `archive` 可单独覆盖（可分盘存放）。
- `src/main/vault.js`：去掉 `ROOT` 缓存 → `defaultRoot()` / `vaultCfg()` / `root()` / `dirs()`（多返回 `custom` 标记）；新增 `moveAll(from,to)`、`countTop(dir)`，导出 `defaultRoot / moveAll / countTop / samePath`。
- `src/main/main.js`：新增 `relocateVault(kind, {useDefault})` + IPC `vault:relocate`。流程＝选目录 → 算 plan → 确认框（报告项目数）→ 校验不重叠（`insideOrSame` 双向）→ mkdir → `vault.moveAll` → `store.set({vault})` → `rewritePathsForMoves`（改写 items / 分组 children / removedPaths / archive.order 前缀）→ refreshDesktop + healPaths + refreshInspect + warmIcons → broadcast。旧目录空则 `rmdirSync`。
- 归一化：选回默认位置 / 落在 `root\同名文件夹` 时不写死路径，避免留下无意义的「自定义」标记。
- UI：`panel.html` 文件页「软件文件夹」三行各加「更改位置」+ 自定义标签 + 「恢复默认位置」；`panel.css` 加 `.vault-tag/.vault-btn/.vault-hint`（说明文字走中性灰，别借用 field-hint 的黄底）；`panel.js` 加 `relocateVault()` 与 `#vaultPathBox` 事件委托，`viewFingerprint` 增补三个路径字段。
- 验证：假 electron 桩跑 node 自检（默认路径 / 搬家 / 单文件夹覆盖 / 落盘）全 PASS；另用临时 Electron 预览器（未被提交）截图确认三行布局与标签正常。
- 注意：Dock 层级 / Win+D 相关代码（zorder.ps1、zorder.js、dock.js、main.js 里的 setAlwaysOnTop 部分）本次一行未动。
