## 规则：版本号只写一处（用户要求，长期有效）

- 落在 `.cursor/skills/deskgow-release/SKILL.md`，`AGENTS.md` 末尾加同名小节指向它。
- 版本号只在两处：`package.json` 的 `version`、README「当前版本」那一行（数字 + 一句用途）。
- PR 描述、发布说明、commit message、README / changelog 一律不叙述版本号变更（不写「版本号改为 x.y.z」「接在上一版之后」「x.y.z 是上一个正式版本」「发布 x.y.z」）。
- 不拿版本号当小节标题。原来是 `## v1.0.0` → 改 `## 功能一览`；`### 测试 1.4.0 / 1.3.1 / 1.3.0` → 按内容命名（桌面小组件面板 / 显示桌面·收纳按钮·自动隐藏 / 文件合集与图标自愈）；FAQ 里「1.0.0 里是这样」→「现在是」。
- PR #3 描述里那句「版本号改为 1.1.1，接在 1.1.0 之后」已删。
- 发版流程随之调整：版本号跟功能改动一起提交，不单独开「发版」提交；PR 目标仍是上一个 release 分支。
