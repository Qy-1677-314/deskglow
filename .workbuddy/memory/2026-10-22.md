## 图像处理方法（可复用）
- **圆角几何**：AI 原图 1024×1024 铺满画布、四角外纯白。四角边界像素最小二乘圆拟合得半径 ≈238-243px（23.3-23.7%），与 Win11 图标圆角一致。
- **alpha 掩膜**：rounded-box SDF（q=abs(p-c)-(half-R)，d=hypot(max(q,0))+min(max(qx,qy),0)-R）4x 超采样取覆盖均值，边缘 AA 自然。
- **AA 环反混合**：原图 AA 像素 = a·shape + (1-a)·white。直接存会让图标在深色底上边缘发白。对 0.12 ≤ a < 0.995 的像素做 rgb=(stored-(1-a)·255)/a 还原纯 shape 色，任意底色复合才正确。
- **AI 水印定位**：右下角半透明「AI/AI生成」字样（约 x894-1024, y954-1000），横跨圆角边界——圆角外部分最终被透明掩膜裁掉，只需修圆角内的一条斜边。检测 = ROI 内 51×51 局部中值背景 + 亮度差 >10（全图降采样扫描会误报图标自身高光，勿用）。
- **水印去除**：核心 mask 膨胀 12px ∩ (alpha ≥ 0.5) 为未知区，拉普拉斯扩散（红黑 Jacobi，1000 步即收敛，单步变化归零）。未知区必须限制 alpha ≥ 0.5，否则白色背景会作为边界条件把圆弧内侧拉出一条亮边。
- **ICO 手写**：ICONDIR + 16B 目录项；≥64px 用 PNG 压缩载荷，<64px 用 32bpp BMP（BITMAPINFOHEADER 高度=2h，自底向上 BGRA + 全零 AND 掩码）。Pillow 读回验证 7 帧齐全、alpha 0-255 正常。
- **方案二去白**（上一轮）：白色图形定位用「不挨边的最大连通块 + BFS 面积最大」，勿用「离中心最近」（会误选 281px 高光点而非 1382px 图形）；修复用扩散勿用双线性拟合（会留差色 ghost）。
